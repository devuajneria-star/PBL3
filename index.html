Project Technical Documentation & Architecture

What is Reinforcement Learning?

Reinforcement Learning (RL) is a branch of Artificial Intelligence where an autonomous agent learns to make sequential decisions by taking actions in an environment to maximize cumulative numerical rewards. Unlike supervised learning, it requires no pre-labeled datasets.

What is Q-Learning?

Q-Learning is a model-free, off-policy tabular RL algorithm that learns an action-value function Q(s, a) representing the expected future utility of taking action a in state s:

Q(s, a) ← Q(s, a) + α [r + γ max_a' Q(s', a') - Q(s, a)]

Why AI for Traffic Signals?

Fixed-time timers waste valuable green time on empty lanes while cross-streets suffer severe congestion. Q-Learning perceives real-time queue imbalances and vehicle waiting durations, dynamically allocating green time to maximize overall throughput and minimize delay.

System Architecture

- Frontend: HTML5 Canvas 60 FPS simulation, Chart.js telemetry, REST API polling.
- Backend: Python 3 Flask REST microservice, car-following kinematic vehicle physics.
- AI Engine: Tabular Q-Learning with epsilon-greedy decay, multi-objective reward formulation.
